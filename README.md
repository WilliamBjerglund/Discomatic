# Discomatic

Discomatic is my attempt at building a Discord bot while learning more about Rust, Discord bot development, APIs, databases, and software development in general.

The project originally started because i wanted a way to track how much time people played league in our local discord server for fun even though more precise sites exist.

Anything else is just more fun things i wanted to see if i could make.

# Current Idea Implementions

- A playtime Tracker for League of Legends only using presense updates
- Simple commands to handle Dice Rolling
- A very Simple and stupid BibTex creator that uses DOI or arXiv for now.
- A very simple music player
